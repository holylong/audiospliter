# 录制指南（自己录一遍 demo）

## 1. 启动

```bash
./start.sh
```

脚本会收掉占用 8010 端口的旧服务、启动后端（监听 `0.0.0.0`），打印本机和局域网两个地址，
然后自动打开浏览器。手机想一起看，就连同一个 WiFi 打开那个 `192.168.x.x` 地址。

只本机可用：`HOST=127.0.0.1 ./start.sh`；换端口：`PORT=9000 ./start.sh`。
局域网访问打不开时先放行端口：`sudo ufw allow 8010/tcp`（服务本身没有登录鉴权，用完记得关）。

手动版：`HF_HUB_OFFLINE=1 .venv/bin/python -m uvicorn app.server:app --host 0.0.0.0 --port 8010`

## 2. 录前设置

| 项 | 建议 |
| --- | --- |
| 浏览器窗口 | **1600×900** 或全屏（F11），缩放 100%，关闭书签栏（Ctrl+Shift+B） |
| 录屏工具 | OBS「窗口采集」选浏览器窗口，或「显示器采集」整屏 |
| 画布 | 1920×1080 · 30 fps · CQP 20 |
| 音频 | 只录**桌面音频**（系统声音），麦克风静音，除非你要口播 |
| 鼠标 | OBS 设置里打开「捕捉鼠标指针」，观众才看得清你点了哪里 |
| 系统声音 | 声音设置里把输出设备设为默认，音量 60% 左右即可 |

## 3. 一段 30 秒就能录完的流程

| 时间 | 动作 | 说明 |
| --- | --- | --- |
| 0–3 s | 鼠标在页面上轻晃 | 让观众先看清界面：左边输入 + 管线，右边结果 + 时间轴 |
| 3 s | 点 **「使用示例对话」** | 不弹文件框，直接用内置的 `samples/双人对话_30s.wav`。想演示上传就从这里拖文件进虚线框 |
| 3–10 s | 手不动，看进度 | 八步管线依次点亮：读取 → 解码 → 加载模型 → VAD → 声纹 → 聚类 → 掩码 → 导出；约 6 秒跑完 |
| 10 s | 点 **说话人 1 的「▶ 试听」** | 听到只有第一个人的 5.9 秒片段，点击处波形会染成已播颜色 |
| 15 s | 点 **说话人 2 的「▶ 试听」** | 换成第二个人的声音，波形颜色也随之切换 |
| 19 s | 点 **「原始混音」那一行** | 放上传的原始文件，时间轴上出现青色播放头，正好和刚才两条轨对比听 |
| 23 s | 点 **「下载」** | 浏览器落盘 `spk1.wav`，按钮文字闪一下「✓ 已保存」 |
| 26 s | 鼠标停在右侧时间轴 | 三条轨（A / B / 原始混音）的回合交替一眼可见，收尾 |

> 想换成自己的音频：把任意双人对话（WAV / MP3 / M4A）拖进虚线框即可，不需要转码，
> 引擎会自己重采样到 16 kHz。超过 1 分钟的素材处理时间会线性变长，录制时建议先剪到 20–40 秒。

## 4. 口播（可选，约 20 秒）

> 「两个人同时说话，录下来就是一段混在一起的声音。这个人声分离工具会把它们拆成两条独立音轨——
> 一条只有说话人一，一条只有说话人二。点击试听：这是第一位的，这是第二位的。
> 全靠声纹嵌入加双人聚类，CPU 上五秒多就跑完，两条轨都能直接下载。」

## 5. 录完检查

- 播放录屏：两个「试听」按钮点击后**确实有声音**（音量条在动）
- 进度条走完、右侧出现两条彩色波形
- 结尾停 1–2 秒再停止录制，剪辑时好切

## 6. 出片

```bash
# 只用录屏原声，裁掉头尾空转，压到发布规格
ffmpeg -i 录屏.mp4 -ss 00:00:01 -to 00:00:31 \
  -c:v libx264 -preset slow -crf 20 -pix_fmt yuv420p -r 30 \
  -c:a aac -b:a 192k -movflags +faststart out/demo-自录.mp4
```
